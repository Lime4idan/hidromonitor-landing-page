# HidroMonitor

Landing page institucional e comercial para a **HidroMonitor**, uma proposta de prevenção e monitoramento em tempo real do fluxo de água.

> Este projeto foi desenvolvido em dupla.

[Acessar o site publicado](https://hidromonitor-green.vercel.app/) · [Ver o projeto no Figma](https://www.figma.com/design/3QW9EVyhcJ7BO7KcyNQqDT/HidroMonitor-Landing-Page)

![Prévia da landing page HidroMonitor](docs/hidromonitor-preview.png)

## Sobre o projeto

A página apresenta como sensores, acompanhamento contínuo e alertas podem transformar variações no fluxo de água em informação mais clara para condomínios, administradoras e equipes de facilities.

O conteúdo evita métricas não verificadas e identifica os gráficos como representações visuais com dados ilustrativos.

## Destaques

- experiência responsiva para desktop e dispositivos móveis;
- apresentação do fluxo sensor → monitoramento → alerta;
- visualização ilustrativa de monitoramento em tempo real;
- seções de aplicações, perguntas frequentes e contato;
- navegação acessível, menu móvel e suporte a `prefers-reduced-motion`;
- identidade visual baseada em preto, branco e azuis da marca.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Inter, Inter Tight e IBM Plex Mono
- Vercel

## Executar localmente

Na pasta do projeto, inicie um servidor estático:

```bash
python3 -m http.server 4173
```

Depois, abra `http://127.0.0.1:4173`.
